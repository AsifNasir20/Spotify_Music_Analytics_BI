# 🎵 Spotify Music Analytics Dashboard

An interactive **Power BI dashboard** designed to analyze Spotify's Top 50 global music charts, exploring song popularity, artist performance, chart rankings, and music trends through dynamic visualizations.

## 📸 Dashboard Preview

[Spotify Music Analytics Dashboard](https://github.com/AsifNasir20/Spotify_Music_Analytics_BI/blob/d48cf170e63ef3fe195ace0088322d5e37b5e32b/Spotify_Dashboard.pdf)

## ✨ Key Features

- 🎶 Interactive Spotify music analytics dashboard
- 🏆 Top 50 global songs and artist performance analysis
- 📊 Song popularity and chart ranking visualization
- 📅 Date-based music trend analysis
- 🎨 Spotify-inspired dashboard design
- 🔍 Dynamic filters and interactive Power BI visuals

## 💡 Key Insights

- 🎤 Identifies popular artists and top-performing songs.
- 🏆 Explores song rankings and popularity across global charts.
- 📈 Tracks changes in music trends over time.
- 🎵 Provides insights into song characteristics and album information.

## 🛠️ Tools & Technologies

**Power BI** · **DAX** · **Power Query** · **Data Visualization**
